unity game project protocol - 149 from 2025 (abandoned). protocol 149 primarily featured a ship that could fly and rotate through 3d space, using this
ship the player would dodge increasingly harder waves of projectiles and missiles which would track the player.

requirements :
  - OS that can run unity editor.
  - unity installed on machine to run the editor.
  - a unity version to run the project in.

install instructions :
    - download repository and unzip.
    - open unity hub and click add then add project from disk.
    - navigate and select unzipped repository.
    - you will be prompted for a version to open it in, selecting missing version or latest LTS version will work best.
    - wait for editor to load and enjoy.

gameplay notes :

the player could accelerate forward and backward(WS), side to side(AS) and also up and down(space/Left control).
the ship could also be rolled left and right(QE) and the player could rotate the ship along the other 2 axis(mouse).
the player could increase the speed of these actions through afterburner(shift).

the player could fire their weapon(lmb) and lock onto a target(R).

using 1,2,3 the player could deactivate aspects of the UI and with p the player could quit the game.

ship : 
  - the ship gave the player the ability to move quickly through space with the intention being the player would use this to dodge pursueing
    missiles, these missiles would appear at regular intervals and the player could either shoot them down using their weapon or wait for them
    to eventually burn out.

  - the ship has a limited pool of resources indicated by the UI, fuel is used for movement, energy is also used for movement but replenishes and
    ammo is used for the main gun.

missions/menu : 
  - outside of the ship the player had a menu, here they could balance their ammo/fuel/energy with more of each making the ship heavier and harder
    to move/dodge. furthermore the player would select missions which would each designed with a set of missiles which would spawn in.

  - in the concept for the full game the player would move through levels sequentially slowly gaining points which would be used to upgrade the
    ship, however this idea scope crept the game and resulted in its abandonement.

missiles : 
  - the main obstacle of the game, they track the player and move to try and intercept. each missile can be customised to have different health,
    rotation speed and acceleration allowing for a variety of different types of obstacles for the player to face.

  - missiles also have a health value which is decreased by the players gun which was added to give the player a more immediate solution to
    pursuing threats.
